# 思考过程可见性 + 流式体验(thinking 增量 + 渲染路径 SSE 化)

## 目标

1. **思考过程开关**:用户可选择是否查看思考条目(默认开启 = 现状折叠条目;关闭 = 完全不渲染),localStorage 持久化。
2. **thinking 增量流**:provider 的 reasoning 从「流结束后整段回放」改为「逐 raw chunk 转发」——SSE 新增 `thinking-delta` 增量帧,客户端原地累积;完整 `thinking` 帧保留为权威终帧(审计与既有 e2e 契约不变)。注:D22 记录 GLM-5.3 reasoning 末尾齐发,当前增益是"到达即快放 + 解除与 decide 返回的耦合",管线为将来真流式就绪。
3. **渲染短路路径 SSE 化**(你的主路径):展示意图 rule 未命中时不再静默等 JSON——SSE 流内先推 thinking-delta,spec 过闸后发 `render` 帧(载荷 = 现 JSON 回执同形状);过闸失败/异常在**同一条流内**交回 agent 循环(诚实失败口径不变)。rule 命中路径保持瞬时 JSON(既有 s5 e2e 不动)。delegated 模式不变(仍 JSON)。

## 改动(TDD:先测后实现)

### A. 协议与前端

1. `apps/web/src/chat/sse.ts`:`ChatSseFrame` 增加 `{type:'thinking-delta'; step; text}` 与 `{type:'render'; payload: ChatRenderPayload}`(payload = respondWithFrozenSpec 的 JSON body 形状,导出类型)。
2. `apps/web/src/components/chat-panel.tsx`:
   - `appendThinkingDelta(step, piece)`:从尾部找同步号思考消息原地追加;完整 `thinking` 帧到达时以全文**替换**累积内容(权威终帧,兼容丢增量)。
   - `render` 帧处理 = JSON 分支等价:`persistSession` + `setLastRender`(自动跳画布 effect 直接复用)+ 追加 `payload.messages`。
   - `showThinking` 状态入 `useChatSession`(悬浮/分栏切换 ChatPanel 重挂载,状态须住壳上——与委托开关同因);localStorage `ui4a.chat.thinking`,缺省 true;runtime 消息映射处过滤(`messages.filter(m => showThinking || m.thinking === undefined)`),不改 thread.tsx 组件树。
   - onFrame 的 else 分支改为仅响应 `error` 类型、忽略未知帧(容忍前向协议扩展)。
3. `apps/web/src/components/assistant-ui/thread.tsx`:composer「委托」旁增「思考」开关按钮(Brain 图标,aria-label「思考过程」/aria-pressed/data-nav="local:chat-thinking",完全对齐委托开关先例 :154-165);`ChatThreadProps` 增 `showThinking`/`onToggleShowThinking`。

### B. Agent 包(packages/agent)

4. `llm-driver.ts`:`DecideSink` 增 `onReasoningDelta?`;`raw` case 内每提取到 reasoning 片段即回调(:292-299 处);末尾聚合 `onReasoning` 不动(审计包装 `wrapDriverForAudit` 契约不变)。
5. `loop.ts`:`RunAgentOptions` 增 `onReasoningDelta?`;`decideSink` 构造条件扩展为 onReasoning 或 onReasoningDelta 存在(:94-105),转发增量。
6. `render.ts` `generateRenderSpecWithLlm`:options 增 `onReasoningDelta?`;`streamText` 补 `includeRawChunks: true`,raw 部件经 `raw-reasoning.ts` 共享解析器转发增量;返回类型不变。

### C. 路由(apps/web/src/app/api/chat/route.ts)

7. 抽取两helper:
   - `frozenRenderPayload(...)`:`respondWithFrozenSpec` 的回执构造(freeze + body 组装);JSON 路径包装 `Response.json`,SSE 路径包装 `render` 帧。
   - `streamAgentLoop({send, ...})`:现 inline 流体(resolveStartRel → runAgent(含 onReasoningDelta/onReasoning/onStep)→ 冗余步帧 → agent-decision/chat-turn 落库 → final 帧,:321-418)。
8. rule miss + `hasDisplayIntent` + mode ≠ delegated → 返回新 SSE 流:先 `generateRenderSpecWithLlm`(增量经 `thinking-delta` 帧,step 恒 1);过闸 → `frozenRenderPayload` → `render` 帧;失败/异常 → `streamAgentLoop` 兜底(流内交回,不换响应形态)。
9. inline 常规路径接 `onReasoningDelta` → `thinking-delta` 帧(步号 = stepFramesSent + 1,与 thinking 帧同号口径)。
