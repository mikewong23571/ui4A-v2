# 用户故事与验收

测试以这些结果为准，不以现有默认值或文案为准。

| 故事 | Given / When / Then | 验收方式 |
| --- | --- | --- |
| S1 未选应用 | 无应用/工作线/对象，问有哪些能力；输入是授权应用摘要，未读取 articles、未声明 publishing；真实回答不制造主应用 | 起点/循环/合同单测，HTTP，真实 LLM |
| S2 共同注视 | 已打开 Meta 应用列表或具体业务对象，提问；保持该对象的合同起点，不被应用偏好覆盖 | route/loop 单测，浏览器 |
| S3 清空与恢复 | 曾选应用/线/对象，再显式清空并刷新；清空不会从旧 presence 复活 | Situation 单测、客户端/服务集成与浏览器 |
| S4 同一件事跨应用 | 一条线显式关联两应用资源且另有无关线；询问目标/进度，Agent 获得本线目标与授权关联对象；不混入另一条线，不自动挂接 | 工作上下文单测/HTTP、真实 LLM、浏览器 |
| S5 应用不是围墙 | 选了 A，Agent 按合同导航到已授权 B；读取 B 的细节，原选择 A 保持；授权外资源不进入上下文或标题/计数 | loop/披露/授权负例 |
| S6 后台延续 | 同一线派发后，浏览器切换到另一线；后台仍按原线读取最新合同，恢复不携带旧事实副本 | Worker/dispatch 集成测试 |
| S7 简洁可核对 | 打开“在哪”；应用选项为合同标题，工作线和对象可识别，关联资源可点击；桌面/390px 不溢出，不增加解释段落 | 组件测试、Playwright、截图 |
| S8 治理与扩展 | 新增 fixture 应用/变更工作线成员/收回授权；无每应用分支、输入重建有界，完整发现不收窄；已有 exec/审批/来源/重放语义不变 | 预算、权限、全量 check/e2e、代码审查 |

真实 LLM 验收只请求阅读/解释，不以批准、发布、运行外部执行器为验收捷径。
