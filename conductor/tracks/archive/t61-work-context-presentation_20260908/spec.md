# T61 工作现场优先与简洁材料交互

用户已确认工作内容为主、材料按需打开、操作就近、文案精简的交互，并明确要求实施。设计来源为本会话 workspace-redesign 原型；其中示例方案、固定阶段与模拟执行不进入产品。

## 范围

- 同一工作线主体通过通用语义呈现区分当前工作与参考材料；主区保留完整可见责任，正在处理的对象可直接阅读与操作。
- 材料收为按需入口，空线不出现独立移出动作。生命周期管理按需披露，讨论接入已有助手会话。
- 添加材料通过有明确目标的选择区完成，候选按规范引用去重，同名可辨，预览不写入，勾选后显式提交，失败保留未完成选择。
- 读取材料不改变当前工作状态；关闭后保留主区与聊天草稿。状态只显示一次，删除教学和重复说明。
- 同一 HTTP/Siren/fresh action read/裁决/事件日志边界。授权裁剪先于材料分类、计数与预览。

## 验收

1. 工作线中材料不抢占主阅读区，当前工作/待决定事项仍可见，所有责任覆盖通过机械校验。
2. 从当前对象或材料入口查看引用，再返回可继续原工作；无新权威存储或副作用。
3. 选择与查看零写入；显式提交结果真实，重复候选只呈现一次，部分失败可重试未成功项。
4. 普通工作主动作与线生命周期管理分开，空引用无移出入口；文案简洁。
5. 聚焦测试、完整 check、相关 E2E、生产构建与实际浏览器走查通过；未知能力/缺事实不伪造内容。

## 边界

不新增按应用/实体类型/业务阶段分支，不新建规则助手、不制造推荐、不修改批准权限。部署按独立发布合同处理，实施完成与线上生效分别报告。T56/T59/T58 的未完成项不在本 Track 自动关闭。
